Como trabalhar a Fila de Projetos de Layout
Perfil: Design · Versão 1.0

Seu acesso ao WizMart CRM é uma única tela: a Fila de Projetos de Layout. Não há gamificação (moedas, streak, ranking) para este perfil. Leia primeiro o Guia Rápido para login e navegação básica.

1Como funciona a Fila de Projetos

Sempre que alguém do time comercial (BDR, SDR ou Representante) solicita um layout de loja num negócio WizMart Minimercado, o pedido cai na sua fila 📐 Fila de Projetos, com todos os detalhes: tipos de PDV, quantidade de equipamentos, dimensões das paredes e observações.

A fila é FIFO — primeiro a chegar, primeiro a sair. O pedido mais antigo aparece no topo.

2Como pegar um projeto para trabalhar

  1. Na fila Aguardando, escolha o pedido do topo (mais antigo).
  2. Clique em Pegar este projeto.
  3. Ele passa para a seção Meu projeto em andamento, no topo da tela.
💡 Um projeto por vez

A tela foi pensada para você focar em um pedido de cada vez antes de pegar o próximo.

3Como marcar um projeto como entregue

  1. No seu projeto em andamento, clique em Marcar como entregue.
  2. Cole a URL do arquivo entregue (Google Drive, etc.).
  3. Clique em Confirmar entrega.

O time comercial vê a entrega automaticamente no negócio correspondente.
